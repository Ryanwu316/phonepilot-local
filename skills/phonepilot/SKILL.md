# PhonePilot

把当前 OpenAI 应用作为 AI，PhonePilot 作为本机设备控制台。无需新 API Key；不使用苹果的「iPhone 镜像」窗口。技能本身不是手机驱动，需要同一台 Mac 上的 PhonePilot 项目及其运行环境。

## 唤起与启动

用户可说「用 PhonePilot 打开手机侧栏，帮我……」，也可显式调用 `$phonepilot`。仅询问功能或使用方法时直接回答，无需启动服务或读取手机画面。

需要实际使用时，运行本技能目录下的辅助脚本（按实际技能路径定位，不依赖聊天当前目录）：

```sh
python3 <skill-dir>/scripts/session.py start
```

脚本复用健康的已有服务，必要时在后台启动只监听本机的 PhonePilot；不会连接、配对或操作手机。输出 JSON 的 `running`、`phase`、`demo` 和 `url`，不输出令牌。只检查状态可把 `start` 改为 `status`。

项目通常由技能的源目录自动定位。若文件被复制或项目迁移，可指定 `--root /绝对路径/PhonePilot`，或由用户配置 `PHONEPILOT_ROOT`。若缺少 `.venv/bin/python`，指出需先运行项目的「首次安装.command」；不安装另一套 AI 服务。

如果运行环境禁止访问或监听本机端口，按实际工具权限流程执行启动/检查，不把沙箱权限问题当成手机故障。

## 在当前应用侧栏操作

- 用 `open_in_codex` 打开脚本返回的 `url`，`placement: "right"`；若不可用，用 CUA 的 in-app browser 打开该 URL。保持这一个控制台，结束时将标签页标记为可继续使用的交付物。
- 检查实际页面状态。服务运行、设备可见、手机已连接、画面已更新和手机已解锁是不同状态。`demo=true` 只能用于演示，不能声称操作了真机。
- 已有连接就复用，不为唤起技能重启服务、断开手机或打开第二条隧道。需要连接时，使用用户选定设备并遵守当次工具的授权要求；多台设备选择不明时只问具体设备。锁屏时请用户手动解锁，不尝试输入解锁密码。
- **当前会话没有 `phone_*` MCP 工具时，直接用 CUA 操作侧栏。** 技能安装不代表 MCP 工具已加载；不把安装 MCP、修改全局配置或重启 OpenAI 应用作为默认前置条件。
- 若 `phone_*` 工具已经可用，复用控制台会话：先 `phone_status`、`phone_screenshot`；坐标使用返回图像的像素尺寸和 `observation_id`。编号 60 秒过期，任何控制操作都会作废旧截图。操作后重新截图，不能重复使用旧编号。
- 使用 CUA 时，以最新侧栏截图定位手机画布中的目标；按实际 CUA 文档交互。辅助脚本只用于启动/状态，不通过脚本、HTTP 接口或其他 UI 自动化绕过 CUA 来点击和输入。

## 数据线与无线

控制台设备设置提供“数据线”和“无线”。尊重用户选择，自动恢复保持原连接方式，不为恢复切换设备或通路。无线要求同一 Wi-Fi 和已有配对；首次尚未准备时，先插线并选择已信任手机，经用户明确授权后才点击“为这部手机准备无线连接”，该操作会在本机保存无线配对凭据。普通连接不进行新配对。不要用插线状态下的画面证明无线已通过；需拔线后验证新画面及实际操作。

## 淘宝包裹查询

用户要求查看淘宝包裹或物流时，读取 [查包裹流程](references/taobao-parcels.md)，逐单检查拆分包裹、最新物流节点和覆盖范围。复制界面中的指令不代表任务已经开始或完成。

## 结果与接手

点按、滑动、长按、输入、App 打开和系统按键均由控制台提供。中文等非 ASCII 文字通过手机剪贴板粘贴，会替换当前剪贴板；不读取旧剪贴板，也不记录输入内容。回车可能提交表单，按用户的具体任务判断。

控制台「暂停控制」会中止当前操作并拒绝后续控制，截图仍可读取。尊重用户的暂停；收到明确恢复要求后可通过控制台恢复，不通过 MCP 绕过暂停。用户说停止时暂停或断开相应会话，不停止其他软件。一般任务完成后保留控制台，除非用户要求断开。

传输成功只说明指令执行。重新观察页面中可验证的结果，再汇报完成状态；涉及发送、下单等动作按当前用户授权与工具规则处理，唤起技能本身不增加这些授权。

## 故障与能力边界

画面停滞或操作失败时先重新观察和检查连接状态。控制台会对原设备进行有次数上限的恢复，期间不要重复下发操作；停止自动恢复后，可做一次与故障相关的人工恢复尝试；仍失败则报告具体状态，不反复点按同一位置，不自动切换设备或连接方式。手机相机/麦克风占用、信任、开发者模式和 Xcode 设备支持都可能影响连接；不擅自改这些设置。

本项目验证过真机画面、计算器点按、App 打开、截图与暂停。视频有过自动重连；中文输入、真机录屏及长期稳定性尚未完成验收。查看当前项目的 `VERIFICATION.md` 获取最新范围，不把以前的演示或单次成功当作新任务已完成。
